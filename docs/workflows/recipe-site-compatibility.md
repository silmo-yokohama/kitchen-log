# レシピサイトの取得可否リスト（url入口／zero入口の参考検索）

`url`入口でWebFetchを使う際、実際に材料・手順まで取得できることを確認済みのサイトの一覧。`zero`入口で参考レシピをWebSearchする際も、ここに載っているドメインを`allowed_domains`に指定する。新しいサイトを試したら、確認結果をここに追記していく。

レシピサイトの調査（掲載レシピ数・公開API有無）は2026-07-08に実施済み。クックパッドが掲載数最多（国内380万〜396万品）。公開の検索APIは楽天レシピのみ（カテゴリ別ランキング上位4件のみ、キーワード検索不可、手順は含まれない）で、他サイトはAPIなし。詳細は当時の会話ログ参照。

（検証日: 2026-07-08。各サイト1件のレシピページをサンプルとしてテストした結果であり、サイト全体を保証するものではない。将来的にサイト側の仕様変更で結果が変わる可能性がある）

## 一部のみ取得可能・要注意

| サイト | ドメイン | 備考 |
|---|---|---|
| macaroni | macaro-ni.jp | 材料は取得できるが、作り方の手順はページ構成上（別ページ/JS読み込み）取得できないことがある。手順が取得できなかった場合はユーザーに確認するか、テキスト貼り付けに切り替える |

## 取得不可（url入口の対象外、text入口に切り替える）

| サイト | ドメイン | 理由 |
|---|---|---|
| YouTube | youtube.com | 概要欄・字幕が動的コンテンツのため取得不可 |
| Instagram | instagram.com | ログイン必須のため取得不可 |
