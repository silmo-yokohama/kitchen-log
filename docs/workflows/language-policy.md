# 言語ポリシー

このリポジトリでの言語使い分けルール。

## 日本語で統一するもの

ユーザー・開発者向けのメッセージは全て日本語で書く。

- git commitメッセージ
- 各スキル（`/new-recipe`等）からユーザーへの出力・確認・質問・会話中の返答
- ドキュメント（README、ユーザー向け説明等）
- PR・issueのタイトル・本文・コメント

## 英語/日本語どちらでも良いもの（コスパ優先）

Claude Code自身に向けた指示書は、英語・日本語のどちらでもよく、トークン効率などコストパフォーマンスを基準に選択する。

- `CLAUDE.md`本体、`docs/workflows/*.md`等のワークフロー定義
- `.claude/commands/*.md`等のスキル定義ファイル
