# 栄養計算・benefits/cautions記述ルール

## エネルギー計算式（固定）

文部科学省「日本食品標準成分表2020年版（八訂）」の計算式を必ず使う。CookGo等、他サービスに表示されている栄養価の値には依存せず、必ずここで自前算出する。

```
エネルギー(kcal) = たんぱく質(アミノ酸組成)×4.0
                 + 脂質(脂肪酸TG当量)×9.0
                 + 利用可能炭水化物(単糖当量)×3.75
                 + 食物繊維×2.0
                 + 糖アルコール×2.4
                 + 有機酸×3.0
                 + アルコール×7.0
```

`nutrition` フィールドの `energyKcal`/`proteinG`/`fatG`/`carbohydrateG`/`saltG` は、この式に基づき1人前（`servings`で割った値）で算出する。

## 拡張栄養素（ビューアのレーダー表示用）

`nutrition` には上記5項目に加え、以下も成分表から1人前で算出する。ビューア詳細ページの「摂りたい栄養素」レーダーチャート（6軸: たんぱく質＋以下5項目）に使う。

- `fiberG`: 食物繊維 (g)
- `vitaminAUg`: ビタミンA (μgRAE、レチノール活性当量)
- `vitaminCMg`: ビタミンC (mg)
- `calciumMg`: カルシウム (mg)
- `ironMg`: 鉄 (mg)

算出ルール:

- 成分表の生値ベースで算出し、加熱による損失（ビタミンC等）は見込まない
- `適量`・`少々`・`ひとつまみ`（amountがnull）の材料は計算に含めない
- レーダーは「多いほど良い栄養素」のみを扱う。食塩・脂質等の「控えたい項目」はここに追加しない（ビューア側の栄養価タイルの高低表示で扱う）

## 食塩相当量の目標値

厚生労働省「日本人の食事摂取基準（2025年版）」より、成人男性 7.5g未満/日、成人女性 6.5g未満/日。`cautions` で食塩について言及する際はこの値との比較で書く。

## benefits / cautions の記述ルール（厳守）

- `benefits`/`cautions` は「計算した栄養素の値」と「公的基準値との比較」からのみ記述できる
- 医学的根拠のない俗説・都市伝説（例: 特定の調味料への漠然とした健康被害の指摘）は禁止
- 計算値が調理・喫食の仮定に依存する場合は、その仮定を `cautions` に明記する（例: 鍋・汁物の食塩相当量は「スープを全量飲んだ場合」の計算値である旨を書き添える。実際の摂取量は食べ方で変わるため、仮定を伏せたまま数値だけで注意喚起しない）
- 該当する内容がなければ、無理に埋めず空配列のままにする

## balance（栄養バランス評価）

- `recipes/*.json` をGrepし、既存レシピの中から組み合わせられるものが**あれば**具体的なレシピ名を提案する。無理に既存レシピを当てはめない
- 具体名を挙げるのは、栄養バランスの補完に加えて料理の系統・味の相性も踏まえ、総合的に「一緒に食卓に並べて合う」と言える場合のみ（例: 麻婆豆腐に野菜コンソメスープは、栄養の数字上は補完になっても料理として合わないので提案しない）
- 合うレシピが無ければ、どのような料理が良いかの記述だけでよい
